This is a program / application that will take a list of assignments and put them in order by relevance using a score system which is decided by an algorithm that takes into account the time it takes to complete the assignment and proximity to the due date

The priority of this project is to create an algorithm that can effectively rate the importance of assignments, UI and presentation are secondary.
Thus why I put most of my emphasis on the MVP because it's the part I care the most about.

MVP: Write an algorithm that can read the current date and the due dates of assignments as well as an expected time to complete the assignment and then rank them by importance
